绘声绘色 儿童 AI 绘本工坊 —— 腾讯云静态网页托管版  v0.5.4
=========================================================

本包里有两样东西：
  static-site\       上传到“静态网站托管”的网页文件（index.html、config.js）
  cloud-function\    可选的云函数 thf-proxy，用来在服务器端保存密钥、代为调用 DeepSeek、Seedream / MiniMax 和腾讯云语音

页面与 Windows 本地版是同一个文件，功能完全一致。

----------------------------------------------------------------
一、两种部署方式，先选一种
----------------------------------------------------------------
方式 A：只上传静态网页（最简单，适合馆员自己用）
  - 只上传 static-site 里的两个文件，config.js 保持不改。
  - 使用者在页面“设置”里填写自己的 DeepSeek 和 MiniMax 密钥，密钥只在他自己的浏览器里使用。
  - 限制：浏览器能否直接访问 DeepSeek、MiniMax，取决于两家是否允许“跨域访问”。
    开发时无法验证；国内不少模型接口会拦截浏览器直连。若页面提示“连不上模型接口”，请改用方式 B。

方式 B：静态网页 + 云函数（推荐，适合读者扫码使用）
  - 密钥只放在云函数里，读者看不到，也不用填。
  - 可设置访问码，防止陌生人消耗额度。

----------------------------------------------------------------
二、方式 A 操作步骤
----------------------------------------------------------------
1. 登录腾讯云控制台，进入 云开发 CloudBase，打开你的环境（没有就新建一个）。
2. 进入“静态网站托管”，上传 static-site 文件夹里的 index.html 和 config.js 到根目录。
3. 用托管提供的默认域名打开即可。

----------------------------------------------------------------
三、方式 B 操作步骤（在方式 A 的基础上）
----------------------------------------------------------------
1. 新建云函数
   - 进入 CloudBase 的“云函数”，新建函数，名称填 thf-proxy，运行环境选 Node.js 18 或更高版本。
   - 把 cloud-function\thf-proxy 里的 index.js 和 package.json 上传（或在在线编辑器里粘贴 index.js 的全部内容）。
   - 本函数不需要安装任何依赖。

2. 函数配置
   - 超时时间：调到 300 秒（生成插图可能需要几十秒；默认的几秒钟一定不够）。
   - 环境变量：
       DEEPSEEK_API_KEY   你的 DeepSeek 密钥（必填）
       ARK_API_KEY        火山方舟 API Key，用 Seedream 画图（推荐，角色更一致；默认 5.0 Flash，页面设置里可改选 5.5）
       MINIMAX_API_KEY    MiniMax 按量付费密钥（可选；ARK_API_KEY 和它至少填一个）
       TENCENT_SECRET_ID  腾讯云 SecretId（可选，朗读用；可用赛珍珠讲解机器人的语音子账号）
       TENCENT_SECRET_KEY 与上面配对的 SecretKey
       ACCESS_CODE        访问码，例如 reading2026（建议填；读者打开网页需先输入）
       ALLOW_ORIGIN       静态网站的域名，例如 https://xxxx.tcloudbaseapp.com（建议填；只允许你的网页调用）

3. 开通 HTTP 访问
   - 进入“HTTP 访问服务”（控制台名称以实际为准），新建路由：路径填 /thf，关联云函数 thf-proxy。
   - 记下访问地址，形如 https://你的环境ID.service.tcloudbase.com/thf

4. 修改 config.js
   - 用记事本打开 static-site\config.js，把最后一行改成：
       window.THF_API = 'https://你的环境ID.service.tcloudbase.com/thf';
     注意结尾不要加 /api，也不要加斜杠。
   - 重新上传 config.js，覆盖原文件。

5. 检查
   - 浏览器打开：https://你的环境ID.service.tcloudbase.com/thf/api/status
     看到 "text":true，以及 "ark":true 或 "image":true，说明文字和画图的密钥已配置好；"tts":true 表示腾讯云语音可用。
   - 打开网页，右上角显示“网页版：DeepSeek · MiniMax”即为成功。

----------------------------------------------------------------
四、常见问题
----------------------------------------------------------------
- 右上角显示“请先填两把 API 密钥”：说明网页没连上云函数。检查 config.js 的地址，以及 ALLOW_ORIGIN 是否和网页域名完全一致（含 https://，结尾不带斜杠）。
- 生成插图时报错或超时：把云函数超时时间调大；若 HTTP 访问服务本身有更短的超时上限，可把插图页数调少后重试。
- 提示“服务器上配置的密钥无效”或“余额不足”：检查云函数环境变量，或到对应平台充值。
- 语音输入需要 HTTPS，静态托管默认域名已是 HTTPS。
- 更新页面：只需重新上传 index.html；config.js 不用动。

----------------------------------------------------------------
五、费用与安全提示
----------------------------------------------------------------
- 每生成一本 8 页绘本，约调用 DeepSeek 6 次、MiniMax 10 次。云函数本身按调用次数和时长计费，量很小。
- 访问码对所有读者相同，活动结束后建议更换。
- 云函数里不保存任何孩子的信息；页面关闭即清除填写内容。
