绘声绘色 儿童 AI 绘本工坊 —— Windows 11 本地版  v0.5.4
====================================================

一、安装（只需一次）
1. 把压缩包里的 TongHuiFang 文件夹整个解压出来（不要在压缩包里直接双击）。
2. 双击 Install.bat。程序会安装到本机，并在桌面和开始菜单生成“绘声绘色”图标，随后自动打开。
3. 第一次打开时，在首页保存密钥（保存一次，以后打开自动使用）：
   - DeepSeek 密钥（必填）：负责全部文字（策划、写作、文学编辑润色、审校、分镜、导读、对谈）
   - 火山方舟 API Key（推荐）：用豆包 Seedream 画定妆图和插图，角色一致性明显好于 MiniMax
       在火山方舟“开通管理”里开通 Seedream 5.0 Flash（推荐）或 5.5，再到“API Key 管理”创建 Key；
       程序默认用 5.0 Flash，可在“设置 → 图片”里改选 5.5、4.0，或填写其他模型编号
   - MiniMax 密钥（可选）：不用 Seedream 时的备选生图模型
   - 腾讯云 SecretId 和 SecretKey（可选）：用腾讯云自然语音朗读故事，
       可直接使用赛珍珠讲解机器人那个有语音合成权限的子账号；在“设置”里填写

不想安装？直接双击 Start.bat 也能运行，效果一样，只是没有桌面图标。

二、日常使用
- 双击桌面“绘声绘色”图标，程序在 Edge 浏览器的独立窗口里打开。
- 关闭窗口约 3 分钟后，后台服务自动退出，不占电脑资源。
- 不用安装任何软件：只用 Windows 11 自带的 PowerShell 和 Edge。
- 程序只在本机开一个自己能访问的小服务（地址形如 http://localhost:17860），局域网里的其他电脑访问不到。

三、密钥安全
- 密钥用当前 Windows 账户加密后保存在 %APPDATA%\TongHuiFang\config.json，换一个 Windows 用户或拷到别的电脑都无法解开。
- 密钥不会出现在网页里，也不会写进导出的绘本文件。
- 删除密钥：在程序“设置”里点“删除已保存的密钥”；卸载时也可以选择一并删除。
- 公用电脑使用完毕，建议删除已保存的密钥。

四、第一次运行时 Windows 弹出提示怎么办
- “Windows 已保护你的电脑”：点“更多信息”→“仍要运行”。
- “打开文件 - 安全警告”：点“运行”。
- 双击后什么都没出现：在压缩包上点右键 →“属性”→ 勾选“解除锁定”→“确定”，再重新解压。

五、遇到问题
- 双击 Start-Debug.bat 启动，窗口会一直显示运行信息，把窗口里的红字截图发给开发者。
- 提示“连不上模型接口”：检查电脑能否上网；学校或单位网络可能需要先登录。
- 提示“余额不足”：到 DeepSeek 或 MiniMax 官网充值。

六、卸载
- 打开安装位置（%LOCALAPPDATA%\Programs\TongHuiFang），双击 Uninstall.bat。

七、文件说明
  Install.bat          安装到本机并创建快捷方式（推荐）
  Start.bat            免安装直接运行
  Start-Debug.bat      带运行信息的启动方式（排查问题用）
  Uninstall.bat        卸载
  app\server.ps1       本地服务
  app\web\index.html   绘本页面（与网页版、静态托管版是同一个文件）
